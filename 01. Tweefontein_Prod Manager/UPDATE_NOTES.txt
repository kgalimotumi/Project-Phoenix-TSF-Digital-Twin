Tweefontein Production Manager v3.9.4 - Daily Plan Minimums
Effective date: 06 August 2026

IMPLEMENTED
1. Waste Rock L/H minimum daily planned = 1,000 m3.
2. Waste Rock Process minimum daily planned = 1,000 m3.
3. Key Cut + RWD Cut to Fill minimum combined daily planned = 3,100 m3.
   - Split proportionally using the source programme ratio.
   - If the source programme is zero for the day, the most recent non-zero
     programme ratio is carried forward so the 3,100 m3 commitment can still
     be allocated proportionally.
4. Process TSF + Process RWD + Roadbed minimum combined daily planned = 2,100 m3.
   - Split proportionally using the source programme ratio.
   - If the source programme is zero for the day, the most recent non-zero
     programme ratio is carried forward.
5. Planned cumulative values are adjusted consistently with the revised daily plan.
6. Original Excel programme values are retained in new source_planned_daily and
   source_planned_cumulative database fields for audit and repeat-safe recalculation.
7. Makanyane default league target = 2,800 m3/day from 06 August 2026 onward.
   Historical dates before 06 August 2026 remain at 2,700 m3/day.

INSTALLATION
1. Close Tweefontein Production Manager completely.
2. Keep your existing folder and especially the entire data folder unchanged.
3. Back up the existing production_manager_sql.py.
4. Copy this production_manager_sql.py into your existing
   C:\01. Tweefontein_Prod Manager\ folder and replace the old file.
5. Start the application normally using run_production_manager_sql.bat.

IMPORTANT
Do NOT replace your data folder with an older copy. The update is code-only so your
current tweefontein_production_v3_9.db, .db-wal and .db-shm remain together.

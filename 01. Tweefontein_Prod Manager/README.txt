TWEEFONTEIN PRODUCTION MANAGER — v3.9.5 RESPONSIVE DISPLAY

INSTALL
1. Close Production Manager.
2. Back up your existing production_manager_sql.py.
3. Copy the included production_manager_sql.py into C:\01. Tweefontein_Prod Manager\ and replace the old Python file.
4. DO NOT replace the data folder or database/WAL/SHM files.
5. Run your existing .bat file normally.

DISPLAY CHANGES
- Starts maximised to the available Windows work area.
- Minimum window size reduced to 900 x 600 for laptop screens.
- Daily Summary controls now wrap into two rows so export/save buttons remain visible.
- Daily Production controls now use two rows so all buttons remain accessible.
- Daily Production graph and table now share available vertical space dynamically.
- Summary table columns contract responsively on smaller screens.
- Sidebar is narrower on 1366-class screens.
- Ctrl+B hides/shows the sidebar to gain extra table/graph width.
- F11 enters/exits full screen; Esc exits full screen.
- Existing v3.9.4 minimum daily plan rules and Makanyane 2800 m3 target remain unchanged.
